# Contrats API

## Statut : IMPLEMENTED (contrat courant)

Contrat généré par FastAPI : `GET /health`, `GET /api/agents`, `GET /api/agents/{agent_id}`, `POST /api/agents`, `POST /api/agents/{agent_id}/transitions`, `POST /api/agents/{agent_id}/evaluations`, `GET /api/tools`, `PUT /api/agents/{agent_id}/permissions/{tool_name}`, `POST /api/agents/{agent_id}/tools/{tool_name}/actions`, `POST /api/approvals/{approval_id}/approve`, `PUT /api/system/kill-switch`, `GET /api/audit/verify`, `GET /api/model/status`, `POST /api/agents/{agent_id}/run`, `GET /api/missions`, `POST /api/missions`, `POST /api/missions/{mission_id}/transitions`, `POST /api/recommendations`. Les routes run et évaluation appellent le modèle configuré localement ; absence du provider = 503, pas de réponse de remplacement. `/openapi.json` est la source générée.
