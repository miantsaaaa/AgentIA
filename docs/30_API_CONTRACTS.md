# Contrats API

## Statut : IMPLEMENTED (contrat courant)

Contrat généré par FastAPI : `GET /health`; CRUD `/api/agents`, `/api/skills`, `/api/knowledge`; liaison `/api/agents/{agent_id}/skills/{skill_id}`; CRUD métadonnées `/api/tool-registry`; actions `/api/agents/{agent_id}/transitions`, `/api/agents/{agent_id}/evaluations`, `/api/agents/{agent_id}/run`, `/api/agents/{agent_id}/permissions/{tool_name}`, `/api/agents/{agent_id}/tools/{tool_name}/actions`; `GET /api/tools`; `/api/approvals/{approval_id}/approve`; `/api/system/kill-switch`; `/api/audit/verify`; `/api/model/status`; CRUD cycle `/api/missions` et `/api/missions/{mission_id}/transitions`; `POST /api/recommendations`. Les routes run et évaluation appellent le modèle configuré localement ; absence du provider = 503, pas de réponse de remplacement. `/openapi.json` est la source générée.
