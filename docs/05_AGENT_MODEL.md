# Modèle d'agent

## Statut : IMPLEMENTED (identité de base)

Un agent enregistré possède slug, nom, domaine, palier, description, niveau, statut, version, compétences prévues et faisabilité gratuite. Connaissances, mémoire, expérience, permissions, modèles, sandbox et historiques spécialisés ne sont pas encore persistés.
