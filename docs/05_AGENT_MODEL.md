# Modèle d'agent

## Statut : IMPLEMENTED (identité de base)

Un agent enregistré possède slug, nom, domaine, palier, description, niveau, statut, version, compétences prévues et faisabilité gratuite. Les compétences sont aussi des entités versionnées avec relation AgentSkill. Connaissances, mémoire, expérience, permissions, modèle assigné, sandbox et historique spécialisé ne sont pas encore reliés à l'identité de l'agent.
