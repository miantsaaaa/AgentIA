# Glossaire

- **Agent** : identité professionnelle composée de capacités, connaissances, règles et versions.
- **Niveau N0-N7** : autonomie certifiée ; N0 est le niveau initial.
- **Palier T1-T5** : ordre commercial de développement, indépendant du niveau.
- **Permission** : autorisation explicite exigée avant une action.
- **Skill** : compétence réutilisable et versionnée.
- **Knowledge pack** : ensemble versionné de connaissances avec provenance/licence.
- **Sandbox** : environnement d'exécution isolé.
- **Benchmark** : scénario reproductible d'évaluation.
