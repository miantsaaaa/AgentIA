# Principes

## Statut : DESIGN

- Refus par défaut pour toute capacité non explicitement autorisée.
- Le niveau est une certification, jamais une saisie libre.
- Les fournisseurs IA et le stockage sont derrière des abstractions.
- Tout état livré est étiqueté selon une preuve réelle.
- Le fonctionnement local sans abonnement est prioritaire.
