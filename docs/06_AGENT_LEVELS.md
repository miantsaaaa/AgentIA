# Niveaux d'agents

## Statut : TESTED (N0→N1)

Les niveaux N0 à N7 représentent une autonomie certifiée. Le POST de création n'accepte pas le champ niveau et crée toujours un agent N0. Le chemin testé N0→N1 fonctionne ; niveaux N2-N7 et catalogue complet de critères restent PLANNED. Le score de démonstration mesure la présence de compétences, pas une capacité de raisonnement réelle.
